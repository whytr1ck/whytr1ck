### About

Frontend developer with **5+ years** of commercial experience building performant SPA and SSR applications. Primary stack is Vue 3 / Nuxt / TypeScript, with solid React and Next.js experience. Shipped production systems serving **2,300+ users across 9 countries** — ERP platforms, fintech investment apps with real-time data, and Telegram Mini Apps.

Beyond feature work: led Vue 2 → Vue 3 migrations, set up CI/CD pipelines from scratch, and introduced code review standards that measurably improved team output. Took on tech lead responsibilities — architecture decisions, junior mentoring, process.
